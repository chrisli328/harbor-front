# Harbor Front (prototype)

A playable HTML prototype of an idle naval defense game: pirates raid your harbor, you launch gunboats, upgrade them in the sheds, hold the gate against the first raid, then push a glowing front line out to sea mission by mission until Ironjaw's flagship comes.

Play: https://chrisli328.github.io/harbor-front/

Built for phones (portrait). The TEST button at the top right opens the prototype test panel (game speed, sound, restart from Mission 1).
